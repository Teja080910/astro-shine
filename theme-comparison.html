User screen fixes

Before / after for the user-screen fixes: the theme-unification pass plus the three Reports issues. Every pair renders in the same mode — switch modes to see how the old hardcoded colors and the new shared tokens behave in light and dark.

01

Bottom tab bar

The floating bar had its own palette. In dark mode the border was a flat slate grey while every card on screen used a gold-tinted border, so the bar read as a separate, colder surface.

07

Reports → My Reports: correct status

The old helper only understood reviewed and dismissed. Anything else — including resolved, closed, approved, in_review, or a typo — silently fell through to "Pending", so reviewed reports looked untouched. Rows that already carried a review date were still labelled Pending.

09

The received list already queries a different endpoint (/reports/received), so the separation was correct in the API — the visible defect was the same status collapse, which showed every ongoing case as "Pending" and every closed case as "Reviewed". Both lists now share the corrected mapping.
