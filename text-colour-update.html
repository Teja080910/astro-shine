What changed and what was kept
  • Every supporting text on light surfaces — specialization, rating, review count, experience, languages, category chip and the Offline label — is now maroon #8D0B0C, the same as the astrologer name.
  • Hierarchy still reads clearly: the name is 15px bold, supporting lines are 9–10.5px.
  • Kept white: the Chat / Call / Video button labels. Maroon on the orange button would be only 3.42:1 contrast and hard to read.
  • Kept orange: the bottom tab labels, as agreed in the previous change.
  • Input placeholders stay a soft neutral so they don't look like typed text.
  • Contrast of maroon on the cream surfaces: 8.6–9.4:1 — well above the 4.5:1 accessibility minimum.
